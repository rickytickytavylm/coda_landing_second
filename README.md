# «Почему я терплю»

Классический статический лендинг второго курса Школы Шурова.

## Состав

- `index.html` — разметка и тексты;
- `styles.css` — дизайн и адаптив;
- `script.js` — меню, вкладки, анимации и модальное окно оплаты;
- `site-config.js` — ссылки, виджет GetCourse и настройки Киры;
- `assets/images/` — изображения для компьютера и телефона;
- `assets/fonts/` — локальные Onest и Literata с лицензиями.

Сборка, Node.js и backend не требуются. Сайт можно разместить на любом статическом хостинге.

## Оплата

Кнопки «Купить курс» открывают встроенную защищённую форму GetCourse. ID и адрес виджета задаются в `site-config.js`.

## Настройки

В `site-config.js` можно изменить:

- адрес администратора;
- адрес технической поддержки;
- виджет оплаты;
- цену и примечание к ней;
- canonical URL;
- отображение Киры AI.

Юридическая информация и ссылки на документы находятся в футере.
